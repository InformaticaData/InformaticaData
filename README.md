# InformaticaData España 📊

**Aprende análisis de datos de forma práctica con datasets reales de España.**

Proyectos completos con datos oficiales (INE, CIS, SEPE, Eurostat, portales autonómicos y municipales…): desde la descarga y la limpieza hasta los gráficos, con código en Python comentado en español y listo para ejecutar.

Pensado para **alumnado de FP** (DAM, DAW, ASIR, SMR, cursos de especialización), **docentes** que buscan prácticas con datos reales y **profesionales que empiezan en datos**.

🌐 **Tutoriales completos en [informaticadata.es](https://informaticadata.es)**

## Proyectos

| Repositorio | Qué aprenderás | Artículo |
|---|---|---|
| [cis-problemas-espana](https://github.com/InformaticaData/cis-problemas-espana) | Extraer tablas de PDF oficiales con `pdfplumber`, armonizar categorías que cambian con los años y animar un ranking con matplotlib (barómetros del CIS, 2018-2026) | [¿Qué preocupa a los españoles?](https://informaticadata.es/que-preocupa-a-los-espanoles-cis-python/) |
| [datos-abiertos-espana](https://github.com/InformaticaData/datos-abiertos-espana) | Descargar datos de las API del INE, Eurostat y portales CKAN (Madrid, Barcelona) y limpiar el paro registrado del SEPE | [Dónde encontrar datos abiertos en España](https://informaticadata.es/donde-encontrar-datos-abiertos-en-espana-11-fuentes-para-practicar-analisis-de-datos/) |

## Cómo están organizados los repositorios

- Un repositorio por artículo, con `README`, `requirements.txt` y scripts numerados por pasos.
- Código comentado en español y probado con los datos reales que se indican.
- Siempre se cita la fuente oficial y sus condiciones de reutilización.
- Licencia MIT para el código.
